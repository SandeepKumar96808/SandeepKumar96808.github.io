# Run This Portfolio

Open PowerShell inside this folder, where `package.json` is visible.

```powershell
npm install
npm start
```

Open:

```text
http://localhost:3000
```

Build for GitHub Pages:

```powershell
npm run build
```

Upload the **contents inside the `build/` folder** to the root of your `SandeepKumar96808.github.io` repository.
