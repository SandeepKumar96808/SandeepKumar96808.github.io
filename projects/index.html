Projects – Sandeep Kumar

Selected projects across medical imaging, vision-language modeling, anomaly detection, classical machine learning, MLOps and time-series learning.

  • Medical Image Analysis for Brain Abnormality Detection: Deep learning pipelines for CT-based brain abnormality classification and segmentation using clinically relevant preprocessing and evaluation protocols.
  • Vision-Language Modeling for Medical and Multimodal Understanding: Multimodal learning workflows integrating visual features and language representations for image-text understanding, contextual interpretation and semantic reasoning.
  • Industrial Visual Anomaly Detection for Automated Inspection: Anomaly detection pipeline for industrial visual inspection using deep feature learning and image-based defect localization to support automated quality control.
  • Human Activity Recognition using Smartphone Sensor Data: Machine learning model to predict user activities from smartphone gyroscope and accelerometer signals.
  • Winery Prediction and Model Serving API: Wine variety classification using customer review data with an API for model serving and deployment-style inference.
  • Bitcoin Trading Bot using Time-Series Learning: Trading bot built using data science, deep learning and time-series analysis concepts over historical market data.
